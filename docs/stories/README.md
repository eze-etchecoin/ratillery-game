# Stories

User stories live here as `GAME-###.md`. See the `create-user-story` skill
for the template.

Status lifecycle: `draft` -> `ready` -> `done`.

- `draft`: has open questions; not implementable yet.
- `ready`: open questions resolved; can enter developer/QA cycles.
- `done`: QA reported PASS on the latest implementation.

QA reports are appended to each story's `QA History` section.

# docs

All project documentation, organized by purpose:

| Folder | Contents |
| ------ | -------- |
| `product/` | Vision and game rules (human-owned) |
| `stories/` | User stories `GAME-###.md` (functional analyst) |
| `bugs/` | Bug reports `BUG-###.md` |
| `architecture/` | Architecture overview and ADRs (`decisions/`) |
| `agents/` | Agent graph documentation |
| `prompts/` | Human-authored task prompts that bootstrap work |

`status.md` (repo root of docs) is the single index of artifacts; every
story, bug, ADR, and product decision must be registered there.

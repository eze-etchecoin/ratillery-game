# Ratillery — Vision

> Tiny rats. Massive damage.

Ratillery is a 2D turn-based artillery tactics game starring military rats,
inspired conceptually by Worms but with its own identity.

## Pillars

- Turn-based tactical combat.
- Artillery and ballistic physics.
- Destructible terrain.
- Multiple weapons and projectiles.
- Expressive 2D sprite-sheet animation.
- Cartoon-military visual humor.

## Visual direction

- 2D side camera, stylized cartoon look.
- Small expressive rats: big heads, recognizable silhouettes, slightly
  oversized weapons, exaggerated animations.
- Base character: grey/brown rat, light belly, pink ears/nose/paws/tail,
  green military helmet, side view, initially facing right.
- Teams differentiated by accessories (helmets, bandanas, secondary colors,
  backpacks, military gear).

## First playable milestone

> A rat can destroy the world.

The initial scenario must eventually support:

1. Showing an animated rat.
2. Showing 2D terrain.
3. Aiming a weapon.
4. Firing a projectile.
5. Simulating a ballistic trajectory.
6. Detecting impact against terrain.
7. Generating an explosion.
8. Carving a crater that destroys part of the terrain.

## Human-owned decisions

The following are never decided by agents (level 3):

- Game vision.
- Gameplay rules.
- Backlog priority.
- Large architectural changes.
- Visual approval / game feel.
